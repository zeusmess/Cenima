# رمشة (Ramsha)

لعبة تعاون بسيطة للويب: عين واحدة ولاعبان.

- **اللاعب ١ · النظرة**: يوجّه الحدقة بالماوس أو اللمس أو `A` / `D`.
- **اللاعب ٢ · الجفن**: يغمض العين ما دام ضاغطًا على `Space` أو زر الرمشة.

الشرارات الزرقاء تُلتقط بالنظر إليها والعين مفتوحة، والوهج البرتقالي يُصدّ بإغماض العين لحظة وصوله. فيها نقاط ومضاعف حتى ×5، و8 مراحل بأسماء (ثم بلا نهاية)، و13 إنجازًا تُحفظ في المتصفح.

## التشغيل

ملف واحد بلا تثبيت: افتح `game/index.html` في المتصفح، أو انشره على أي استضافة ملفات ثابتة (مثل GitHub Pages) وشارك الرابط.

اللعب على جهازين منفصلين يعمل فقط عند فتح اللعبة كـ Artifact داخل Claude (يعتمد على ميزة `room`). في غير ذلك يختفي الزر وتعمل اللعبة على جهاز واحد.
