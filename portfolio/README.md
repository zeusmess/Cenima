# 🎬 Portfolio — بورتفوليو سينمائي

موقع بورتفوليو عصري بطابع سينمائي (Film grain، Letterbox، Ken Burns، Lightbox) — عربي وإنجليزي، ومتجاوب مع الموبايل. ملفات HTML/CSS/JS بس، من غير أي تثبيت.

## إزاي تحط شغلك (3 خطوات)

1. **الصور:** حط صورك في فولدر `images/` (شوف `images/README.md`).
2. **البيانات:** افتح `content.js` وغيّر اسمك، تخصصك، الأعمال، النبذة، والإيميل/الواتساب. كل عمل = بلوك واحد في `works`.
3. **جرّب:** افتح `index.html` في المتصفح مباشرةً.

> أي صورة لسه مش موجودة بيظهر مكانها إطار مؤقت شيك فيه اسم الملف — عشان تعرف لسه ناقص إيه.

## المميزات

- فلترة الأعمال حسب التصنيف (التصنيفات بتتعمل لوحدها من `categories`).
- عرض الصورة كاملة بالضغط عليها، مع التنقل بالأسهم أو السحب على الموبايل.
- زرار تبديل اللغة عربي ⇄ English (الموقع بيفتكر اختيارك).
- زرار واتساب ولينكات السوشيال.

## النشر مجاناً على GitHub Pages

Settings ← Pages ← Source: `Deploy from a branch` ← اختار الفرع وفولدر `/ (root)`،
وبعدها الموقع هيبقى على: `https://<username>.github.io/<repo>/portfolio/`

أو اسحب فولدر `portfolio` كله على [Netlify Drop](https://app.netlify.com/drop).
