## الملفات

## تعديل أي حاجة

كل التعديلات في `content.js`:

- **تغيير كلام:** دوّر على الجملة وغيّرها. كل جملة ليها نسخة `ar` ونسخة `en`.
- **مسح عمل:** امسح السطر بتاعه من `items`، مثلاً `{ v: "ramadan", r: 0.562 },`
- **مسح حملة كاملة:** امسح البلوك بتاعها من `groups` (من `{` لحد `},`).
- **إضافة عمل:** حط الملف في `media/`، وضيف سطر في الحملة:
  - فيديو: `{ v: "اسم-الملف", r: 0.56 }` (ولازم صورة غلاف `اسم-الملف.webp`)
  - صورة: `{ i: "اسم-الملف", r: 0.75 }`
  - `r` = العرض ÷ الطول: طولي 9:16 = `0.56`، مربع = `1`، عرضي 16:9 = `1.78`
- **حملة جديدة:** انسخ بلوك حملة من `groups` وغيّر الاسم والوصف والأعمال.
- **رقم الواتساب / الانستجرام / الإيميل:** في `contact` آخر الملف.

ضغط فيديو وعمل غلاف بـ FFmpeg:

```bash
ffmpeg -i in.mp4 -vf "scale=-2:720" -c:v libx264 -crf 27 -movflags +faststart -c:a aac media/my-video.mp4
ffmpeg -ss 1 -i in.mp4 -frames:v 1 -vf "scale=-2:720" media/my-video.webp
```

**الأسهل:** ابعت لـ Claude اللينك والتعديل اللي عاوزه (مثلاً "ضيف الفيديو ده في حملة رمضان")، وهو يعدّل وينشر على نفس اللينك.
